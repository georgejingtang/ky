# 阅读真题精析检索

网页：开启 GitHub Pages 后访问 `https://georgejingtang.github.io/ky/jiexi/`

- 搜英文单词：在题干和选项里找；如果题干和选项里没有，会退到原文定位段落里找。多个词要同时出现。
- 搜题号：`2023年22题`、`2023-22`、`2023 第22题`；还能加 `英语一` / `英语二`、`Text 1` / `第1篇` 缩小范围。
- 搜中文：在答案、分析和排错标签里找，如 `偷换说话人`。
- 搜索结果可以直接复制网址分享，例如 `.../jiexi/?q=2023年22题`。

## 新增一道题

所有内容都在 `data/questions.json` 里，网页不用改。

1. 如果这篇文章还没有，在 `passages` 里加一篇：

```json
{
  "id": "2024-英语一-Text2",
  "exam": "英语一",
  "year": 2024,
  "text": 2,
  "paragraphs": ["第一段原文", "第二段原文", "..."]
}
```

2. 在 `questions` 里加一题，`passage` 填上面的 `id`：

```json
{
  "passage": "2024-英语一-Text2",
  "num": 26,
  "context": [
    { "p": 3, "text": "题目对应的原文段落，==定位句用两个等号包住==，其中 **关键词用两个星号包住**。" }
  ],
  "stem": "题干 ______.",
  "options": { "A": "...", "B": "...", "C": "...", "D": "..." },
  "answer": "B",
  "answerZh": "正确选项的中文意思",
  "basis": ["定位与依据，一段一个字符串"],
  "map": [["原文表达", "选项表达"]],
  "note": "可选：补充说明",
  "wrong": [
    { "k": "A", "tag": "无中生有", "text": "排除理由" }
  ]
}
```

`context`、`basis`、`note`、`wrong.text` 里都可以用 `==黄底==` 和 `**加粗下划线**`。`map` 和 `note` 可以省略。

保存前检查一下 JSON 格式（逗号、引号都要是英文半角）；格式错了网页会显示“题库加载失败”。在 GitHub 网页上直接编辑这个文件、提交到 main，大约一分钟后网站就会更新。
